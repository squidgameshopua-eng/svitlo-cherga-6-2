# SVITLO 2.0 — безплатний суспільний бот

**Мета:** без реклами, підписок, платежів і монетизації. Для власника та всіх мешканців — 0 грн.
**Важливо:** функціонування на безплатних тарифах можливе лише до їхніх лімітів. Не можна чесно гарантувати необмежену кількість користувачів, постійну доступність і нагадування рівно за 5 хвилин без фінансування.

## 1. Один бот — багато адрес, чатів і людей

- **Один Telegram Bot Token** на весь сервіс. Токен безплатний. Платні розсилки Telegram вимкнені.
- **Отримувач:** незмінний Telegram `chat_id` — особистий чат, група або канал.
- **Адреса:** запис у захищеній базі, не в GitHub.
- **Підписка:** пара «отримувач — адреса — підтверджена черга».
- **Налаштування:** окремі для кожної підписки, а не глобальні для всього бота.
- **Друкована назва:** користувач задає «Дім», «Робота», «Для мами», «Офіс» тощо.
- Для групи або каналу в особистому кабінеті адміністратора додається поточна назва чату.
- Навіть однакові назви розрізняються за внутрішнім номером підписки та `chat_id`.
- За замовчуванням адреса не відображається у відкритих повідомленнях групи/каналу.
- Адміністратори перевіряються через Telegram при кожній зміні налаштувань.
- Користувач із багатьма адресами може отримувати їх в одному чаті чи в різних чатах.
- Сервіс не пересилає повідомлення однієї підписки іншому `chat_id`.

Приклад **особистого** меню власника (умовні назви):

```text
📋 Мої адреси та отримувачі

👤 Особистий чат · №1
Назва: Дім
Черга: 6.2
Нагадування: вимкнено

👥 Група «Наш будинок» · №2
Назва: Будинок
Черга: 6.2
Нагадування: за 15 хв

📢 Канал «Інформація для мешканців» · №3
Назва: Квартира батьків
Черга: 3.1
Нагадування: за 30 хв, за 5 хв
```

Поточний експериментальний код підтримує окремі підписки, їх перелік, приватний вигляд, видалення і міграцію групи в супергрупу. Реальний інтерфейс /start, /my_addresses, /settings, /delete **не розгорнутий**.

## 2. Нагадування перед відключенням

Після успішного вибору адреси:

```text
✅ Адресу збережено.
⏰ Чи нагадувати перед плановим відключенням?

За замовчуванням нагадування ВИМКНЕНО.

☐ За 5 хвилин
☐ За 15 хвилин
☐ За 30 хвилин
☐ За 1 годину

[Зберегти вибір]
[Не нагадувати]
```

- Без натискань **не існує жодного завдання нагадування**.
- Позначка ще нічого не активує. Потрібно натиснути «Зберегти вибір».
- Можна позначити декілька часових інтервалів; кожна позначка — окреме повідомлення.
- «Не нагадувати» скасовує очікувані нагадування, **але не відключає інформацію про графіки**.
- Нагадування створюються лише з повного підтвердженого добового графіка ГПВ.
- Передбачено окремі нагадування для кожного початку відключення.
- Після офіційної зміни/скасування старі неактуальні завдання скасовуються.
- При зміні адреси/черги необхідно перевірити, що попередні завдання теж скасовані.
- Якщо ДТЕК не опублікував графік заздалегідь, неможливо нагадати про ще невідоме відключення.
- Якщо доставка стала неможливою, бот не надсилатиме застаріле нагадування після початку відключення.
- Точність 5/15/30/60 хв є **цільовою, а не гарантованою**, особливо при масових подіях.

## 3. Безоплатна інфраструктура: кандидат

| Складова | Безплатний варіант | Межа |
|---|---|---|
| Код | Публічний GitHub | Без особистих даних і токенів |
| Прийом Telegram webhook | Cloudflare Workers Free | 100 000 запитів/добу |
| Адреси й налаштування | Cloudflare D1 Free | 5 млн прочитаних і 100 000 записаних рядків/добу, 5 ГБ |
| Перевірки ГПВ | Кешування на рівні оператора і черги | Доступність різних ОСР не гарантована |
| Планувальник нагадувань | Окремий cron/черга в безплатних квотах | Періодичність і доставка можуть затримуватись |
| Надсилання Telegram | Безплатний Bot API | Близько 30 повідомлень/с сумарно |

Значення квот необхідно перевіряти перед розгортанням і періодично після нього.
Workers Free має обмеження CPU 10 мс/запит. D1 Free з вересня 2026 року
**припиняє виконувати запити після досягнення денного ліміту**.

Безплатний Worker **не може бути просто заміною Python + Playwright**, якщо оператор блокує HTTP і вимагає браузерного доступу.
Можливий гібрид: GitHub Actions тільки для публічних графіків операторів, Worker для приватних налаштувань і підготовки сповіщень.
GitHub Actions cron може запізнюватися або пропускати запуск.
Рішення для всіх операторів України потребує окремих адаптерів та перевірки умов користування даними.

- https://developers.cloudflare.com/d1/platform/pricing/

## 4. Не допустити зависання і масового спаму

Принцип: **отримати графік один раз на чергу, розіслати тільки зміни зацікавленим чатам**.
Не робити окремий повний запит до ОСР для кожного користувача.

Прототип уже містить:
- Обмеження 30 адресних підписок на одного отримувача. Це захист безплатного тарифу.
- Короткі назви адрес (до 60 символів).
- Чергу з `pending / leased / sent / cancelled`, повтор після збою.
- Одне повідомлення на чат для декількох одночасних відключень, коли це можливо.
- Цільову швидкість не вище **25 відправлень за секунду**.
- Не більше **1 повідомлення за секунду на чат**.
- Не більше **18 повідомлень на хвилину для групи**.
- При перевищенні лімітів завдання переносяться, а не видаляються.
- Час зберігається в UTC; користувачу показується український час.

Однак SQLite — це лише одно-процесний прототип.
Для багатьох серверних реплік потрібні транзакційна БД та спільний обмежувач.
Диспетчер має перевіряти `retry_after` від Telegram і обробляти timeout.

**Математична межа:** 100 000 окремих повідомлень при 30/с займають не менше 55 хвилин.
Жодне кешування графіків не усуває цю межу безплатної розсилки.
Не можна приховувати від користувачів або власника ризик затримки.

## 5. Безпека та приватність

- Не зберігати реальні адреси, `chat_id`, токени чи базу користувачів у публічному GitHub.
- База тільки в захищеному сервісі. Ключі — лише у секретах хостингу.
- Шифрування диска/БД, TLS, обмеження доступу, резервне копіювання.
- Реальні адреси й Telegram ID належать до персональних даних у контексті ідентифікованої особи.
- Система зберігає мінімально необхідне. Без телефону, ПІБ чи геолокації, якщо вони не потрібні.
- Немає спільного публічного переліку користувачів/адрес.
- Для особистого чату права — за реальним Telegram user ID.
- Для груп/каналів перевіряти права поточного адміністратора через Telegram.
- При видаленні підписки прибирати налаштування і завдання, а спільний кеш залишати тільки якщо іншим він потрібен.
- Відключати підписку при виході бота з групи або втраті прав.
- Не надсилати повідомлення від імені іншого чату, навіть якщо його назва однакова.
- У групі/каналі за замовчуванням показувати короткі мітки, а не адресу.
- Створити політику конфіденційності й процедуру видалення даних.

## 6. Що НЕ готове

- Немає розгорнутого Cloudflare Worker або D1.
- Немає реального Telegram webhook чи обробки /start на всій території України.
- Немає повного реєстру адаптерів операторів, зокрема адрес, які обслуговує не ДТЕК.
- Немає промислового моніторингу, резервного відновлення та гарантії доставки.
- Прототип Python не підключений до чинного бота в гілці main.
- Ставити галочку у цьому документі не запускає бот: потрібне розгортання.
