# SVITLO — Черга 6.2

Telegram-бот публикует график отключений **очереди 6.2** и сообщает об изменениях.
Публикуются графики на текущий и следующий день, когда они доступны у источника.
В сообщениях бот не показывает адрес дома и название оператора.

## Источник данных

Для корректного получения расписания программа использует региональный источник
`dnem` (ДТЭК Дніпровські електромережі) и группу `GPV6.2`.
Город, улица и номер дома не требуются.

Источник: https://www.dtek-dnem.com.ua/ua/shutdowns

## Настройка

1. Добавьте своего бота Telegram администратором тестового канала, разрешив публикацию сообщений.
2. В GitHub откройте **Settings → Secrets and variables → Actions → Secrets**.
3. Создайте **Repository secret** с именем `TELEGRAM_BOT_TOKEN`. Значение — секретный токен нового бота от BotFather.
4. Создайте второй **Repository secret** с именем `TELEGRAM_CHAT_ID`. Значение — `@username` публичного тестового канала или числовой ID группы.
5. Откройте **Actions → Check DTEK schedule → Run workflow**. Убедитесь, что сообщение появилось в тестовом канале.
6. После удачного теста создайте **Repository variable** `BOT_ENABLED` со значением `true`.

**По умолчанию автоматические проверки не выполняются, пока BOT_ENABLED не установлен в true.**
Ручной запуск разрешён для проверки.

## Работа

- Проверка расписания по планировщику примерно раз в 10 минут. GitHub может задерживать выполнение.
- Повторное сообщение не отправляется, если график не изменился.
- Сообщения не являются подтверждением фактического наличия света при аварийных отключениях.
- Часовой пояс: Europe/Kyiv.
- Сохранение состояния отправок: `bot_state.json`.
- Для смены очереди можно установить Repository variable `DTEK_GROUP`. По умолчанию `6.2`.

## Безопасность и стоимость

- Токены и ID приватных чатов нельзя записывать в исходные файлы.
- Репозиторий публичный. Секреты GitHub Actions не появляются в исходном коде.
- Стандартные GitHub-hosted runners в публичном репозитории не расходуют оплачиваемые минуты Actions.
- При изменении публичности проверьте актуальные условия оплаты GitHub.
- Старый приватный репозиторий нельзя делать публичным из-за данных в истории коммитов.
