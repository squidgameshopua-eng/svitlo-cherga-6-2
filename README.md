# SVITLO — Черга 6.2

Telegram-бот публикует график отключений **очереди 6.2** и сообщает об изменениях.
Публикуются графики на текущий и следующий день, когда они доступны у источника.
В сообщениях бот не показывает адрес дома и название оператора.

## Источник данных

Для корректного получения расписания программа использует региональный источник
`dnem` (ДТЭК Дніпровські електромережі) и группу `GPV6.2`.
Город, улица и номер дома не требуются.

Источник: https://www.dtek-dnem.com.ua/ua/shutdowns

## Настройка

1. Добавьте своего бота Telegram администратором тестового канала, разрешив публикацию сообщений.
2. В GitHub откройте **Settings → Secrets and variables → Actions → Secrets**.
3. Создайте **Repository secret** с именем `TELEGRAM_BOT_TOKEN`. Значение — секретный токен нового бота от BotFather.
4. Создайте второй **Repository secret** с именем `TELEGRAM_CHAT_ID`. Значение — `@username` публичного тестового канала или числовой ID группы.
5. Откройте **Actions → Check DTEK schedule → Run workflow**. Убедитесь, что сообщение появилось в тестовом канале.
6. После удачного теста создайте **Repository variable** `BOT_ENABLED` со значением `true`.

**По умолчанию автоматические проверки не выполняются, пока BOT_ENABLED не установлен в true.**
Ручной запуск разрешён для проверки.

## Работа

- Проверка расписания по планировщику примерно раз в 10 минут. GitHub может задерживать выполнение.
- Повторное сообщение не отправляется, если график не изменился.
- Сообщения не являются подтверждением фактического наличия света при аварийных отключениях.
- Часовой пояс: Europe/Kyiv.
- Сохранение состояния отправок: `bot_state.json`.
- Для смены очереди можно установить Repository variable `DTEK_GROUP`. По умолчанию `6.2`.

## Правила публикации

- **Сегодня:** отдельное сообщение только при наличии подтверждённой суточной таблицы с интервалами отключений.
- **Завтра:** отдельное сообщение только после появления подтверждённой суточной таблицы. Недельный прогноз её не заменяет.
- **Неделя:** отдельное сообщение с явно обозначенными *возможными* интервалами. Недельная таблица показывается, только если в текущем суточном графике региона на сегодня или завтра есть действующие ограничения. Это защитный фильтр: наличие шаблона на неделю само по себе не доказывает применение отключений.
- **Изменение:** при изменении интервалов сообщение отправляется повторно с пометкой об обновлении. Для суточного и недельного графиков ведётся независимая проверка.
- **Нет графика:** Telegram-сообщение не отправляется.
- **В опубликованной таблице нет отключений (только белые интервалы):** сообщение не отправляется.
- **Нет текущих ограничений, но есть фоновый шаблон недельного графика:** недельный прогноз не отправляется.
- **Неизвестный статус или ошибка ДТЭК:** соответствующее сообщение не отправляется.
- **Без изменений:** сообщение не отправляется.

Важное ограничение: если ДТЭК опубликует только недельный прогноз, без подтверждённого активного суточного графика региона, бот **не отправит** этот прогноз. Такой фильтр выбран, чтобы не публиковать ненужные предупреждения при отсутствии ограничений.

**Скасування підтверджених відключень:** бот надсилає одне повідомлення українською, якщо попередньо вже повідомляв про відключення на конкретну дату, а нова повна таблиця ДТЕК містить лише інтервали зі світлом. Якщо відключень не було від початку, бот мовчить.

**Часткове скасування та зміни часу:** бот публікує оновлений суточний графік і загальну тривалість запланованих відключень. Для нових станів він також зберігає попередні інтервали, щоб явно показувати доданий або прибраний час. У старих записах стану залишилися тільки контрольні суми; для першого оновлення без попередніх інтервалів бот покаже повний новий графік без детального порівняння.

**Повторна поява відключення після скасування:** бот окремо повідомляє про новий план.

**Скасування тижневого прогнозу:** публікується лише за умови, що попередній прогноз уже був надісланий, а нова тижнева таблиця повністю підтверджує відсутність прогнозованих відключень.

**Важливо:** відсутність даних, неповна таблиця або помилка джерела не є доказом скасування. У цих випадках бот мовчить. Відсутність *планового* відключення не гарантує відсутність аварій.

**Усі повідомлення Telegram — українською мовою.** Тривалість планових відключень показується окремо від можливих.

Приклади всіх повідомлень: [Шаблони сповіщень](docs/notification-examples.md).

Бот не видаляє старі повідомлення Telegram. При скасуванні він надсилає нове повідомлення про зміну.

Официальный недельный прогноз находится в разделе «Графік можливих відключень на тиждень» на странице https://www.dtek-dnem.com.ua/ua/shutdowns. Это отдельный блок сайта, не вкладки «на сьогодні / на завтра».

## Безопасность и стоимость

- Токены и ID приватных чатов нельзя записывать в исходные файлы.
- Репозиторий публичный. Секреты GitHub Actions не появляются в исходном коде.
- Стандартные GitHub-hosted runners в публичном репозитории не расходуют оплачиваемые минуты Actions.
- При изменении публичности проверьте актуальные условия оплаты GitHub.
- Старый приватный репозиторий нельзя делать публичным из-за данных в истории коммитов.
